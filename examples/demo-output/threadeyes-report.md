## How to read it

> Spend is shown as **% of the total**, weighted with each model's API price. It is **not** what you pay: with a subscription it is only a way to compare how heavy each thread is. A thread and its hand-offs count as one. The timeline runs from the oldest week (left) to the current one (right); "·" is a week with no use. "What it does (%)" splits its actions into build (write and edit files) / test (run code, tests, git, browser) / read (open and search) / coordinate (messages and plans). The Fable, Opus, Sonnet and Haiku columns say which share of the thread's spend went to each model; if two weigh 20% or more it is marked "2": the thread does jobs of different difficulty, so pick the model per task. Suggestions suggest, they do not decide.
